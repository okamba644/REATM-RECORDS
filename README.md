# REATM RECORDS

Site vitrine de **REATM RECORDS**, maison de production musicale à Rabat et Salé.

Page unique, sans dépendance de build : HTML, CSS et JavaScript embarqués dans `index.html`.

## Les 5 pôles

| Pôle | Activité |
|---|---|
| **REATM Studio** | Enregistrement, arrangement, mixage, mastering, répétition |
| **REATM Academy** | Formation musicale et média |
| **REATM Prod** | Podcasts, émissions, programmes de prières, courts métrages |
| **REATM Store** | Location, achat et vente d'instruments et de sonorisation |
| **REATM Events** | Concerts, conférences, séminaires, mariages |

## Ce que contient la page

- Mise en page responsive de 320 px à 1920 px
- Menu plein écran sous 1080 px, ouverture par révélation circulaire
- Thème clair / sombre persisté, visuel du hero adapté au thème
- Animations au défilement, cartes en bascule 3D, parallaxe léger
- `prefers-reduced-motion` respecté

## Structure

```
index.html      la page complète
assets/         les visuels (logo, studio jour/nuit, visuels des pôles)
```

## Consulter en local

Ouvrir `index.html` dans un navigateur, ou servir le dossier :

```bash
python3 -m http.server 8000
```
